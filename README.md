# Campus Connect Portal

A unified digital platform connecting students, faculty, and administrators. Developed for CS3301 - Full Stack Development.

## Project Structure

- `client--/`: Frontend application built with React and Vite.
- `server/`: Backend service built with Node.js and Express.

## Getting Started

### Prerequisites
- Node.js (v18 or later recommended)
- npm

### Installation & Running

#### Client
```bash
cd client--
npm install
npm run dev
```

#### Server
```bash
cd server
npm install
npm run dev # or npm start
```
